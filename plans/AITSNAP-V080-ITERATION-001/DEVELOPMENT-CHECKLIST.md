## W01 — 双热键（≤5h）

- [ ] 数据模型包含每动作主/备用两槽，旧3字段迁移不丢值；备用默认空。
- [ ] 设置可分别录入/清空/启用；支持组合键及支持范围内单键，非默认抢占字母键；F12保留键给具体提示。
- [ ] 显式 binding→action 映射，不能将6个热键索引直接当3个动作索引。
- [ ] 规范化/去重、同动作重复、跨动作冲突、外部注册失败、旧注册恢复失败均有可操作结果。
- [ ] 设置录入时不误截图；暂停/恢复涵盖两槽，不因保存配置意外取消暂停；长按不连发。
- [ ] 主窗/托盘显示真实两套绑定；每个动作可单独关闭热键，不影响鼠标入口。
- [ ] 回归旧格式/重启/保存失败回退；两槽分别触发相同动作，验证文件数/序号/剪贴板/Word入队副作用。
- [ ] 原生系统注册与实际输入验证分层记录；PostThreadMessage不是物理键证明，工具不支持某键不是该产品键必然失效。

## W03 — 迷你窗（≤5h；优先交付体验）

- [ ] 主窗/托盘入口；单主按钮、动作下拉、当前配置、忙碌和结果状态。
- [ ] 共用三动作及捕获状态；默认保存，模式可记忆，不意外复制缓存或启动时截图。
- [ ] 拖动、置顶可选、位置持久化、布局变化后回可见区域；关闭回托盘、切回主窗、退出语义明确。
- [ ] 捕获单次执行/忙碌防重、失败反馈；不额外激活被测应用或抢焦点。
- [ ] 自身遮挡处理后真实像素检查，正式截图没有迷你窗残影/黑块；隐藏恢复也不造成白屏或失联。
- [ ] 深浅色/系统、中英文及不同DPI；与热键/托盘并存，无重复采集线程。

## W02 — Word 可选文字与自定义字符串（≤6h）

- [ ] 标题/图注/上下文三类开关和模板，固定字符串、多行、字段说明、例子和无需Word的预览。
- [ ] 只写图片预设；inline/table均不额外插入关闭文字的专用空段落，结构必需段落允许保留。
- [ ] 旧设置迁移保留原默认文字；禁用Word和纯复制不创建任务/文件。
- [ ] 明确字段白名单、转义/未知字段错误、缺值/时间格式；中文、换行、引号和花括号覆盖。
- [ ] 在任务创建时从捕获快照冻结文字/开关，重试不受后续重命名/语言/模板变化影响。
- [ ] 旧v1任务/已有指纹、按日路由、明确路径、同文档FIFO/失败阻塞/UNCERTAIN/COMMITTED重放全部保持。
- [ ] 无文字也保留隐藏提交标记和来源哈希；不能用删除恢复保护实现“清空文字”。
- [ ] 现代Word合成文档：新建→追加→关闭重开，纯图/只标题/只图注/自定义信息，inline/table及混合页方向；核对文字、图数、顺序、尺寸和来源哈希。
- [ ] 队列纯逻辑/故障测试无需Office可先做；新版helper真实执行若受策略拒绝，记TOOL_POLICY_HOLD并保留拒绝，不改入口绕过。

## W04 — 实时来源服务（≤8h）

- [ ] 后台采集/受限订阅和最新帧覆盖；独立于证据批次生命周期，Qt控件只在GUI线程更新。
- [ ] 同屏来源复用帧，缩略降采样，像素/内存/队列有界；退出/暂停/无订阅时停止并释放资源。
- [ ] 初始2fps工程参数、刷新/暂停设置；实际刷新率和延迟测量后决定默认档，不虚构FPS。
- [ ] 正式截图优先；预览可丢帧但正式捕获不可混入旧帧，配置generation隔离切换/删除/重建区域。
- [ ] 逐项证明预览刷新不写图片、不增sequence、不造batch、不排Word、不写历史；内存预览与证据目录无耦合。
- [ ] 最新帧时间/采集跨度和实时/暂停/失效状态；锁屏、断屏、改分辨率/布局不把旧帧当新帧。
- [ ] 先测当前GDI路径的自身排除及重叠图窗；记录API返回和真实像素，不以返回TRUE等同下层图像正确。
- [ ] 不支持排除时明确重叠限制/暂停提示；Win10旧版本与Win7不得静默产生黑块或递归。
