## BRAND-01：统一图标

`src/main_window.cpp:56` 用 QPainter 在单张 64×64 QPixmap 上绘制相机，再用于窗口和托盘。仓库未给主 EXE 配置正式 `.rc/.ico` 资源；MSI 没有统一 Icon/ARPPRODUCTICON，Shortcut 的 Icon_ 未指定。因此不能说完全“没有图标”，准确结论是**只有运行时小图标，缺少部署后的系统入口资源**。

要求一个审定的 SVG 母版，生成多尺寸 ICO/PNG；窗口、托盘、EXE、快捷方式、应用列表、安装向导均使用同源标识，不允许各画一个近似图。16/20/24/32/40/48/64/128/256px，含透明背景和小尺寸可辨认测试。

Windows Shell 中原始 `.msi` 文件通常使用安装器关联图标；ARPPRODUCTICON 不能被当成“必然改变每个 MSI 文件在资源管理器中的图标”。若必须让**分发安装文件本身**也有品牌图标，推荐后续提供薄 `AITSnap-Setup-x64.exe` 作为主入口、内部仍调用同一 MSI；这是真正新增的打包工作，不能只改个 MSI 属性就宣称满足。不要改机器的 `.msi` 全局关联。Bootstrapper 也不能用于绕过工具的 MSI UI 控制限制。

参考：[ARPPRODUCTICON](https://learn.microsoft.com/en-us/windows/win32/msi/arpproducticon)、[Icon table](https://learn.microsoft.com/en-us/windows/win32/msi/icon-table)。Shortcut 的图标容器/扩展约束须按实际快捷方式类型核对，不盲套 `.ico`。

## SCENE-01：文字独立绘制

`scene_editor.cpp:161–163` 先在占位 QImage 上绘制文本，再交给 `LayerItem`；后者调用 `paintLayerLocal` 缩放整个图像，文字自然一起被缩放。0.6.1 修正了占位的宽高比，**没有解决文字/背景耦合**。

区分三层：①不可变源截图；②编辑器身份/操作覆盖层（始终清晰，不导出）；③用户可选的输出题注（独立文字层，在最终画布分辨率上绘制）。不能把真实截图中本来就有的文字“自动转成矢量”，截图内容放大后模糊属于栅格源的边界；本任务修复软件自己叠加的文本。

推荐画布标签位于视图空间，字号/描边使用逻辑像素；文字不跟图层非等比变换，选择框、编号和拖拽手柄也独立处理。导出 PNG 必然栅格化，题注在目标分辨率重新排版；要求可编辑题注时 Word 使用真实段落/Caption，后续矢量导出另行立项。
