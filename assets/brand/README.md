# AITSnap brand assets

`aitsnap.svg` is the single production master. It follows the crop-frame mark from the reviewed concept direction. All PNG sizes and the ICO are derived by `tools/generate_brand.py` with the existing Qt SVG renderer; there are no separately drawn small or dark logos. Original project artwork, Apache-2.0. Final Owner visual/brand acceptance remains separately recorded.

The ICO contains 16, 20, 24, 32, 40, 48, 64, 128 and 256 px PNG frames. Qt windows/tray, PE resources, MSI shortcut/ARP/wizard and the branded setup launcher use this same ICO. Raw `.msi` file association remains a Windows Installer system icon; Setup.exe supplies the branded distribution entry without changing system file associations.
