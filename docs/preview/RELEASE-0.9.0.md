# AITSnap 0.9.0 现场工作流候选版

- 取帧后恢复主窗、迷你窗和捕获操作，裁切、图像写入与清单提交在后台按序完成。队列受容量和像素预算限制，饱和时提示未受理。
- 截图区域可以跨连续的活动屏幕。覆盖判定拦截桌面外缘和屏幕间隙。已经保存的区域可重新框选。
- 新拼图使用原图或区域物理像素。排布预设、导出尺寸和视图缩放分别控制。画布边界、尺寸和缩放比例在编辑时可见。
- Word 队列显示原因、建议操作及可复制诊断。可移除单项或清空，保留写入不确定的任务，并从历史查看取消和归档。
- 新数据目录从零个源开始，首次框选后即可截图。生产载荷由白名单控制，合成测试夹具从源码仓库按需取得。

现代 Windows x64 候选提供 Setup、MSI 和便携 ZIP。操作方法见[操作手册](OPERATOR-MANUAL.zh-CN.md)。精确产物、校验和及安装与运行资格见交付回执。
