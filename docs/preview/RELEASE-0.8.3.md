# AITSnap 0.8.3 实用功能更新

## 图片保存方式

“设置 → 保存”新增两种方式，默认沿用“每次截图新建批次文件夹”。切换为“图片直接保存到输出目录”后，原图/导出图和拼图集中在所选目录，方便人工浏览，重名自动编号，不覆盖已有图片。

直接模式的批次清单放在`.aitsnap/batches`内部子目录，仍能在“批次与报告”浏览、历史重排和加入Word。JPEG导出额外保留无损PNG源证据，避免把有损图当作原始证据。不要手动删除记录目录；移动或改写来源图片会导致历史/报告来源校验失败，不会静默改写历史。纯复制仍不创建图片或记录目录。

同一输出目录可以同时存在两种模式产生的批次。按日自动Word报告仍位于所选输出目录，不会误建在内部记录目录。

## Word文字帮助与测试

“设置 → Word报告”增加“文字字段规则与示例”，无需联网或启动Word即可查看完整说明。中英文说明也随包提供：[中文](WORD-TEXT-FIELDS.zh-CN.md)、[English](WORD-TEXT-FIELDS.en-US.md)。包含各类字段、图片专属字段、固定文字、多行、花括号转义、UTC时间、缺值和任务快照规则。

新增三类文字开关的全部8种组合×inline/table共16组任务契约测试，检查原图/拼图字段、旧任务指纹、修改后冻结、历史批次及路径模式。本轮另有8组真实现代Word合成文档测试，覆盖创建、追加重开、纯图及选择文字、重复提交与源图片不变；确切证据见交付回执。现代Word通过不替代Word2010或人工版式验收。

修复纯图片表格连续追加时的顺序问题：Word可能自动合并相邻表格，现在只向新增行插入图片，保留先前批次的顺序及内容，不再把新图插进旧行并留下空行。

Word可能按其文档设置压缩或重采样较大的嵌入图片；输出目录的原图/拼图文件保持原尺寸和哈希。本轮分别核对外部源文件、文档内顺序及实际嵌入尺寸，不把Word重编码后的字节当作原文件哈希。

## OLED黑与NASA Punk

在“设置 → 外观”选择，立即预览并点击“应用配置”保存。现有浅色、深色、跟随系统保留。

- OLED黑：主背景与内容底色为纯黑，使用灰色边界和青绿色强调，保持文字及选中项可辨。
- NASA Punk：米白、石墨灰、航天橙的工业复古配色；不包含NASA官方标志。

主题只改变界面，不改变截图像素、拼图背景设置或报告内容。界面语言仍为简体中文/English，可跟随系统。

## 兼容与交付边界

设置升级为schema6，首次应用/保存前保留旧v1–v5配置原字节备份；旧配置缺省按批次文件夹，不会擅自改保存目录。旧版无法读取schema6，需要回退时使用保留的旧配置，勿覆盖新旧文件。

正式截图继续默认兼容显示和隐藏自身窗口。0.8.2显示器组合记忆、0.8.1热键冲突恢复及0.8.0双键/迷你/实时服务保留。最终截图测试必须通过后才允许打包。Win10/Win7/Word2010、安装器和人工验收依交付回执保留相应HOLD。
