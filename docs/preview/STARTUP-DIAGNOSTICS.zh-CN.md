# 启动阶段诊断

白屏现象目前尚未在允许的组件环境中复现，不能宣称已修复。0.7.1 提供可选 `--startup-trace 新JSONL文件完整路径`，供后续原生复现时区分配置/队列加载、构造、事件循环与绘制分发。

例：从自己的命令行运行安装后的 `aitsnap.exe --show --startup-trace C:\已有目录\AITSnap-startup.jsonl`。目标文件必须不存在，已存在时退出4且不覆盖；每次复现使用一个新文件名。默认运行不生成日志。若已有实例仍运行，日志只记录锁已占用，后续激活现有实例不会产生新主窗构造阶段。

阶段 elapsedMs 从进程入口计时；首条日志在 QApplication 初始化和参数解析后，不能排查其前的故障。`event-loop-first-turn` 表示首个排队回调已执行，`main-first-paint-dispatched` 仅表示绘制事件分发，不能代替原生像素、实际响应或人工验收。日志不包含截图、配置正文和文档正文。

当前桌面停止和安装器工具限制保持。本说明只提供后续诊断方法，不授权绕过限制、关闭未知进程或修改系统权限。Windows10/Win7、安装Finish首次打开及人工视觉结果仍需独立回执。
