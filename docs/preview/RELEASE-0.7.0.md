# AITSnap 0.7.0 安装候选

0.7.0 将配置表单改为五个浏览式页面：工作台、源区域、拼图场景、批次与报告、设置。原截图、渲染、Word 队列与事件管线继续使用。

- 工作台显示源卡、显示器分布和下一次输出；选择拼图会高亮所引用来源。未采集、布局占位、最近批次与旧尺寸有明确区分。
- 源区域默认进入显示器布局；区域浏览保留实际图片比例。框选界面、卡片、图层使用稳定区域编号和名称。框选内 F2 可改名；取消不保存。
- 拼图标签独立于图片变换，编辑标记不写入导出。默认“等比适配”允许留白；关闭时拉伸目标框，这是明确的输出选项。
- 新文件和批次目录使用可读名称；历史路径和 UUID 引用不迁移，旧 Word 作业及指纹保持原样。
- 批次与报告浏览已保存图片；“将本批加入报告”读取冻结快照及哈希，不重新截图。同一批次和报告已有任务时转到现有状态，不重复插入。
- 设置分七类，新增“外观”：简体中文、English、系统语言；浅色、深色、跟随系统。配色立即预览，应用后保存；语言重启生效。系统配色变化会更新界面，不改变源图或导出像素。
- 同一 SVG 派生 16–256px 图标，覆盖窗口、托盘、PE、快捷方式、卸载入口及安装向导。品牌 Setup EXE 内嵌完整 MSI，只校验并启动系统安装器，不下载依赖。
- 欢迎/路径/完成页保留；安装提交先进入准备页，并显示真实安装动作。完成页和快捷方式显式使用 `--show`，与启动到托盘的偏好分开。

## 安装与数据

双击 `AITSnap-0.7.0-windows-x64-setup.exe`，或直接运行配套 `AITSnap-0.7.0-windows-x64.msi`。安装前从托盘退出旧版。完整包离线附带运行库及中文 Qt 标准控件翻译，不要求安装 Qt SDK/Python。

配置升级前保留旧版原字节；已有区域 UUID、场景引用、报告任务和历史证据不改写。显示器排列/DPI/旋转变化会触发重新校准要求；不宣称已实现多套显示器环境自动识别、保存与切换。

## 验证界限

当前为可体验的安装候选，精确包哈希、源 SHA、检查结果见执行回执。源/组件检查、原生安装交互、目标系统、人工批准分别记录。Qt6.12 的 Windows10 1809+ x64 支持范围不等于本应用已经取得 Win10 原生验收。

Owner 当前没有 Win10 目标；Win7 v142/x86/x64、Word2010、最终可见安装/启动链路及 Owner 视觉批准仍 HOLD。已知旧样本的系统还原点等待为 20.236s；准备页改善反馈，尚无新首帧/总耗时实测，不承诺缩短系统调用。此前按物理 Esc 停止桌面控制，隐藏组件渲染不替代这些门槛。
