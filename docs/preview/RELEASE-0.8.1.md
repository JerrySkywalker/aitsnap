# AITSnap 0.8.1 热键冲突修正

修复0.8.0中已保存快捷键被其他程序占用后，打开区域编辑器、拼图编辑器、迷你窗及鼠标截图均被阻止的问题。Windows错误1409代表该快捷键已被注册；它只应影响键盘触发，不能让编辑功能失效。

已有快捷键未修改时，注册失败保留清楚的警告，但允许保存其他设置、进入编辑和用鼠标截图。主动更改快捷键时，仍检查语法、重复和系统冲突；新绑定不可用则拒绝该次更改，保留旧配置。用户主动暂停仍按原语义生效；恢复时注册失败不会再次强制暂停鼠标截图。

提示现在显示具体动作名称和按键，而非只有“动作1”。可在“设置→快捷键”更换冲突键或停用该动作的全局热键，不要求删除配置、提升权限或结束其他软件。0.8.0中的双键、Word文字、迷你窗和实时预览功能继续保留。

修正前可临时从托盘暂停截图热键以进入编辑器；安装此修正版后，不应再需要该临时步骤。升级前正常退出旧版AITSnap，保留原配置与输出目录。安装器实际点击受工具策略限制，包校验/组件测试与实际安装验收分开记录。Win10/Win7/Word2010及人工视觉的既有HOLD保持。
