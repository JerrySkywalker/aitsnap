# AITSnap 0.8.0 候选版

0.7.2 基线上的功能更新：双热键、可配置 Word 文字、迷你截图窗、实时工作区和独立图窗。实际测试/包来源及剩余 HOLD 见 `plans/AITSNAP-V080-ITERATION-001` 执行与交付回执。本文件不代表完整平台或人工验收已通过。

- 三种截图动作各有主、备用两套全局键，可同时使用组合键和单键；旧主键保留，备用默认空。可单独停用某动作的热键，鼠标入口继续可用。编辑热键字段时暂停注册；应用配置会检查启用键的系统冲突。F12 为系统保留键。
- Word 批次标题、图片说明及上下文可分别关闭，支持固定字符串和有限字段模板，并提供预览。选择“只写图片”关闭可见文字。原配置默认保留原有图文格式；已有排队任务仍按创建时的冻结指令执行。
- 主窗/托盘可进入迷你窗，用鼠标选择截图动作、暂停/恢复或返回主窗，记忆位置、动作与置顶偏好。关闭迷你窗回托盘。
- 实时工作区显示当前来源和拼图，不必先保存截图；可切换最近截图。区域或场景可以打开独立图窗、暂停及置顶。正式截图仍重新采集，预览不会生成批次文件、消耗序号或追加 Word。

实时刷新上限可选1/2/5fps，默认2fps，实际性能以本机测量为准。隐藏/最小化且没有其他订阅时停止刷新。锁屏、来源变化或失败会标明状态；多显示器采集不是硬件同步曝光。图像与区域标题分层显示。

独立图窗绑定当前配置的区域/场景；切换到不含该来源的配置时需要切回。图窗保留比例，截图按钮执行当前配置的完整保存动作。“复制当前预览”仍只复制显示缓存的预览分辨率。实时编辑不能把未保存来源当成历史证据导出，正式截图/历史重排沿用原有流程。

自身窗口排除能力取决于实际系统及捕获路径；不支持时，重叠来源提示移动图窗，不把黑块当成功图像。本版实时图窗是本地实时画面，未提供鼠标穿透、远程串流或虚拟摄像头。

现代候选使用 Qt6 x64。Win10 实机/清洁目标、原生 Win7 x64/x86 与合格工具链、Word2010、必需人工 M1–M5 签收仍分项 HOLD；Qt5 在 Win11 上构建不等于 Win7 通过。新版 Word 文字分支的真实 Office 排版/追加验收需独立证据，组件测试和旧版 Word16 证明不替代它。

安装包维持欢迎、路径、进度、完成及“立即启动”流程。旧0.7.2配置在首次保存新版格式时保留备份。程序、截图和报告位置分离；安装器 UI 操作受现有工具策略限制时，由 Owner 手动完成并单独记录，不能凭包表检查声称实际安装已验收。
