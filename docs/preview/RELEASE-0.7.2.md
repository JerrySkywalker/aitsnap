# AITSnap 0.7.2 启动与动作修正候选

已复现并修复重新打开托盘隐藏实例时的白窗路径：原Win32 ShowWindow只显示HWND，Qt主窗/子控件仍隐藏；现在由已运行实例在Qt线程中showNormal，并向发起方确认。原生Qt6/Qt5失败前后回归、真实开发主窗绘制/点击切页已验证。首次冷启动与安装器Finish全链路须在最终包上另记回执，不能把此修复等同于所有启动资格。

三种动作明确且复用：截图并保存（默认Ctrl+Alt+S）、截图并复制（Ctrl+Alt+C，仅复制所选新截图，无文件/Word）、截图保存并复制（Ctrl+Alt+A）。主窗按钮/托盘/全局热键共享命令并采用同一当前UI草稿快照，保留旧自定义组合键。图片浏览的“复制当前预览”/Ctrl+C只复制已显示缓存的预览分辨率，不重新截图、落盘或消耗捕获序号。框选/编辑区域的Ctrl+Shift+R为应用内配置快捷键。

沿用0.7.1保存生命周期、批量管理、统一面板、默认按日Word等修正。配置schema及旧Word任务指纹不变。Win10、Win7、Word2010仍分别需要真实目标机资格；本机Win11/Qt5宿主结果不替代它们。
