# Word 写入文字与字段

在“设置 → Word 报告”中选择文字预设，或分别设置“批次标题”“图片说明”“上下文信息”。文字预览不需要启动 Word。

## 固定文字、字段与开关

- 可以直接输入固定文字，例如 `试验记录：热真空测试`，也可以混合字段，例如 `第 {sequence} 次截图 · {profile}`。
- 勾选的文字项才会写入。选择“只写图片”会关闭三类可见文字，图片仍正常写入；Word 表格/图片自身必需的结构段落仍存在。
- 标题与上下文每批写入一次，图片说明按每张输出图分别展开。关闭标题不会关闭图注，反之亦然。
- 在输入框按回车可以写多行；输入两个字符 `\n` 不会自动转换成换行。
- 字段区分大小写。每个模板最多4096个字符。未知字段或不成对的花括号会提示位置，修正后才接受已启用模板。
- `{{` 输出一个 `{`，`}}` 输出一个 `}`。例如 `{{固定}} {profile}` 会输出 `{固定}` 加配置名称。

## 三类文字都支持的字段

| 字段 | 含义 |
| --- | --- |
| `{profile}` | 本次截图的配置名称 |
| `{datetime}` | 本次采集的UTC时间，ISO格式，例如 `2026-11-02T04:00:00.000Z`；`Z`表示UTC，不是本地时间 |
| `{sequence}` | 本次截图序号；旧批次没有记录序号时为空 |
| `{test}` | 试验标识 |
| `{device}` | 设备标识 |
| `{station}` | 工位标识 |
| `{operator}` | 操作人 |
| `{run}` | 关联运行标识 |
| `{step}` | 关联步骤执行标识 |
| `{command}` | 关联指令调用标识 |
| `{event}` | 关联事件标识 |

没有填写或没有关联的数据展开为空字符串，不会自动编造值。关联运行/步骤等字段来自所选上下文；不是任意Word字段或代码表达式，不支持额外日期格式指令。

## 仅图片说明支持的字段

| 字段 | 原图 | 拼图 |
| --- | --- | --- |
| `{name}` | 区域名称 | 场景名称 |
| `{label}` | 编号与名称，例如 `#2 电压` | 场景名称与版本，例如 `对比图 r3` |
| `{number}` | 区域编号 | 空 |
| `{kind}` | `ORIGINAL` | `COMPOSITE` |
| `{scene_revision}` | 空 | 场景版本号 |

这些图片字段不能用在批次标题或上下文模板中；同一批有多张图时，每张图使用自己的名称、编号和类型。

## 可复制的例子

标题：`试验 {test} · 第 {sequence} 次截图`

图片说明：`{label} | {datetime}`

上下文（可以按回车分行）：

```text
设备：{device}
工位：{station}    操作人：{operator}
运行：{run}    步骤：{step}
```

如果只需要图片下方固定写“测试结果”，关闭标题与上下文，保留图片说明并填写 `测试结果`。如果不想写任何可见文字，选择“只写图片”。

## 保存、重试与历史批次

点击“应用配置”保存设置。新任务创建时冻结已展开的文字；后续修改模板、区域名称、界面语言，不会改变排队任务或重试内容。历史批次加入报告时，图片/时间/序号使用该批快照，文字模板使用加入报告时选定的设置。

“截图并复制”不保存图片，也不加入Word任务。只有保存类动作在启用Word时自动加入报告；也可以手动把已保存批次加入报告。请先用自己的合成文档检查版式；任务状态、失败恢复和文档实际效果分别查看，不要对待核对状态盲目重复写入。
