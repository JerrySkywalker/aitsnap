# AITSnap 0.7.0 候选版操作手册

当前可体验：多屏多区域截图、托盘/快捷键、区域校准、自由拼图、Word 异步队列、静态目录与只读事件关联。当前主机为 Win11；Win10、Win7、Word 2010、人工视觉验收仍为 HOLD。

## 启动与安装

MSI 用户从开始菜单运行 AITSnap，标准数据目录是用户本地应用数据目录下的 AITSnap。便携体验可运行 `Launch-Preview.ps1`，使用独立的 `AITSnap-preview-0.7` 目录。也可直接运行 `aitsnap.exe`，或使用 `--tray` 启动到托盘、`--data-dir D:\AITSnapDemo` 隔离设置、队列、上下文及初始截图输出。已保存配置中的输出路径保持原值，可在窗口中调整。

正式安装候选使用 `AITSnap-0.7.0-windows-x64.msi`，提供开始菜单、修复、升级和 Windows 标准卸载。目标为 Win10 1809+ x64 / Win11；当前 Win10 原生验收仍 HOLD，详见安装说明。

便携包也支持按用户复制：在包目录执行 `powershell -File .\install-preview.ps1 -Destination "$env:LOCALAPPDATA\Programs\AITSnap-preview"`，目标必须尚不存在。此方式不注册 Windows Installer；也可直接搬迁整个解压目录。

卸载前从托盘退出，等待当前截图完成。MSI 用户在 Windows“应用和功能/程序和功能”中卸载 AITSnap Preview。便携包才使用 `uninstall-preview.ps1`，它保留未知和已修改文件；MSI 安装目录会拒绝这个便携卸载脚本。两种方式均保留安装目录之外的设置、截图和报告，不自动删除用户证据。

## 浏览与外观

工作台的左侧是源卡片，中间为显示器与区域分布，右侧是下一次输出及预览。点击输出查看其来源；双击进入相应页面。源区域默认显示器布局，第二个子页浏览选中区域最近采集图片。名称/编号可在卡片和框选界面识别，卡片双击或框选 F2 改名；保存新区域后编号不复用。

拼图场景浏览现有场景预览，勾选参与输出，再打开原有画布编辑器。尚未采集时为布局占位。批次与报告显示磁盘上已保存的图片，支持用本批重排或追加到明确的 Word 报告；这两个动作都不覆盖原图。报告已关联该批次时查看原任务。

设置分常用、外观、保存与命名、Word 报告、上下文、快捷键、托盘与自启。外观选择中文/English/系统语言及浅/深/系统配色。颜色立即预览，点击应用配置保存；语言重启生效。应用主题不修改截图和拼图输出颜色。

## 截图与拼图

1. 选择或创建截图配置，打开区域编辑器，在各屏幕上拖选区域并保存。显示器排列、旋转或 DPI 改变后重新校准。
2. 设置输出目录、PNG/JPEG、文件名模板和保存/复制/两者快捷键。默认 Ctrl+Alt+S、Ctrl+Alt+C、Ctrl+Alt+A；冲突会显示状态提示。
3. 在场景编辑器选择预设，拖动/缩放图层，设置裁剪、旋转、显示、锁定和层级，使用对齐、分布、吸附、分组与撤销。保存修订后选择原图、拼图或两者输出。
4. 点击截图或按快捷键。每批保留清单、原始 PNG 及哈希；JPEG 为派生导出。可从历史批次按已保存场景重新渲染，不改变源图。
5. 关闭主窗口继续驻留托盘；托盘可显示窗口、截图、暂停快捷键或退出。锁屏时拒绝桌面捕获，不生成伪成功图片。

各显示器由 GDI 依次读取，并非硬件同步快照；跨屏时间差在清单和性能记录中保留。人工应检查多屏 DPI、负坐标、遮罩、裁剪边缘、文本清晰度和托盘交互。

## Word 队列

填写明确的 `.docx` 目标路径，启用报告，选择连续图片或两列表格。截图完成独立入队，Word 后台进程处理，不使用当前活动文档作为隐含目标。写入前校验源图哈希；每作业有持久标记和提交状态。

队列显示排队中、正在写入、已保存提交、等待重试、失败、待核对，完整状态码与路径可通过提示查看。修改前错误最多自动尝试三次；失败和待核对会暂停同一报告后续写入，其他报告仍可继续。排除 Word/文件原因后，选中有修改前失败证明的作业，点击“已排除原因：重试所选修改前失败任务”，原任务身份、顺序和历史保持不变。

`UNCERTAIN` 仍须先保存并检查文档，再执行标记检查；失败重试入口不接受 UNCERTAIN 或已提交作业。禁止复制同一作业盲目重插。关闭/崩溃后保留作业及临时文档。已有未保存编辑或受保护文档会在修改前拒绝写入。

只在自己的合成测试文档上初次体验。已有文档未保存、只读或受保护时应先解除对应状态。当前自动化验证覆盖本机 Word 16；未证明 Word 2010 或人工排版验收。

## 合成上下文与接口

导入 `synthetic-demo` 中的目录 JSON/CSV，显式选择完整且唯一的序列版本。事件通过 `aitsnap-cli.exe` 或 `metadata_host.py` 发送，命令说明见 `aitsnap-cli.exe --help` 和仓库 `docs/architecture/LOCAL-HOST-API.md`。

本地管道限定当前登录身份，只提供元数据操作。执行事件不触发真实设备命令；事件到截图的规则默认空，须明确配置。无运行序列的 v2 事件可保持 UNLINKED；不可猜测运行上下文，也不记录参数值。

## 验收与来源

查看包内发布说明、构建/DLL 来源清单及 `licenses`。每次安装前安装脚本验证包文件哈希。当前包是本地有限预览，不是 Win7/10/11 全平台发布。正式支持和 M5 人工验收须另行完成。
